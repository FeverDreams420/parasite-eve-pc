/*
 * Overlay ABI: addresses the overlays use that main's code does not
 * name. The disc loader places every overlay at a fixed offset in the
 * overlay window block and overlays reach each other's code and their own
 * run-time memory outside their file images at fixed offsets, so these
 * stay fixed relative to the block on purpose. Every entry is a window of
 * linkers/USA/overlay_windows.txt plus an offset: the block itself follows
 * main, the field engine and the boot work area, and the window symbols
 * come from the built main executable. Every other main address an
 * overlay uses is linked by name from the built main executable
 * (tools/scripts/overlay_link_symbols.py, docs/CODE_ORGANIZATION.md
 * "Shiftability"). Addresses in the comments are retail addresses.
 *
 * Each block names the owner of the memory and why it is fixed; each
 * entry lists the overlays that reference it. An entry is linked only
 * into the overlays that reference it.
 */
