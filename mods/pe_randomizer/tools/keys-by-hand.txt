# One rule only: a key may go to a chest in the same room as its own spot (any version of that room).
# The player is in that room exactly when they would have picked the key up, so every key turns up
# when it does in the unmodified game. Rooms holding a key check (keyscan.py CHECK rows) are left out,
# so no chest sits behind a lock of its own room: M154 (Elevator Key) keeps its key. Keys without a
# chest in their room keep theirs too. Medium and Hard move the same keys.
#
# needs: the keys of the days before (all the game asks while a day's keys arrive as in vanilla).
# before: the room's own key(s) only. Days 2 and 5 have no candidate chest and stay without data.
# Replace with keylogic.py output from logged play when there is one.
